# Discrete Mathematics — Course Notes

Detailed notes for each module of the discrete math / mathematical logic course, written to support DSA learning (proof techniques, set theory, combinatorics, and their links to hashing, cryptography, and algorithm design).

## Contents

| File | Module | Topics |
|---|---|---|
| [module1-notes.md](./module1-notes.md) | Module 1 — Mathematical Logic & Proof Techniques | Propositions, logical connectives, truth tables, tautologies/contradictions, logical equivalence & laws, converse/inverse/contrapositive, necessary vs sufficient conditions, rules of inference, predicates & quantifiers, normal forms (CNF/DNF), proof methods, induction, well-ordering principle, pre/postconditions & invariants |
| [module2-notes.md](./module2-notes.md) | Module 2 — Set Theory, Relations & Functions | Sets, power sets, set operations & identities, Cartesian products, cardinality, inclusion-exclusion, countable vs uncountable sets, Cantor's diagonalization, relations & properties, equivalence relations/classes, partial/total orders, Hasse diagrams, lattices, closures, functions (injective/surjective/bijective), floor/ceiling/modulo, hashing functions, pigeonhole principle |
| [module3-notes.md](./module3-notes.md) | Module 3 — Combinatorics & Counting | Sum/product rules, permutations & combinations, stars-and-bars, binomial theorem, Pascal's identity, inclusion-exclusion (general form), derangements, generalized pigeonhole, key-space sizing, birthday problem/collision counting, recurrence relations, generating functions, Catalan numbers |

## How these notes are organized

Each module file follows the same structure:
- Numbered sections matching the syllabus order
- Definitions and formulas in tables for quick lookup
- Worked examples for every major technique
- A **Quick Reference Summary** at the end of each file for fast review
